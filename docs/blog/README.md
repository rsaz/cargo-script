# Blog Post Series — `cargo-run` 0.6

This directory contains a four-post launch series announcing the v0.6 release
and positioning `cargo-run` as the **workspace-aware, RFC-3502-ready task
runner for Rust**.

| # | File | Audience | Channel |
|---|------|----------|---------|
| 1 | [`01-announcing-cargo-run-0.6.md`](./01-announcing-cargo-run-0.6.md) | Rust devs, existing users | `/r/rust`, *This Week in Rust*, dev.to, Hacker News |
| 2 | [`02-workspace-orchestration.md`](./02-workspace-orchestration.md) | Workspace maintainers | dev.to, *This Week in Rust* |
| 3 | [`03-cargo-script-integration.md`](./03-cargo-script-integration.md) | Power users / RFC followers | dev.to, RFC 3502 issue thread |
| 4 | [`04-migrating-from-just-make-cargo-make.md`](./04-migrating-from-just-make-cargo-make.md) | `just` / `make` / `cargo-make` users | dev.to, `/r/rust`, project READMEs |

Posts are written in CommonMark with a small front-matter block so they can be
re-published verbatim on dev.to, Hashnode, Medium, or a Zola/MdBook site.

## Suggested release cadence

- **Day 0** — Post 1 (launch announcement) on `/r/rust` + Hacker News.
- **Day +2** — Post 2 (workspace deep dive) — submit to *This Week in Rust*.
- **Day +5** — Post 3 (cargo-script integration) — cross-link from RFC 3502 tracking issue.
- **Day +10** — Post 4 (migration guide) — repost on dev.to and link from README.

See [`../../COMMUNITY_OUTREACH.md`](../../COMMUNITY_OUTREACH.md) for the wider
outreach checklist (RFC engagement, *TWIR* submission template, social copy).
